# 文中画像

## 保存方式

- 画像本体はプロジェクト内の `picture/inline/` にコピーする。
- `data.json` には画像ID、相対パス、元サイズだけを保存する。
- 各指示文・カギ文には、画像ID、挿入文字位置、表示サイズ、黒塗り方式、
  改行フラグ（`line_break`、画像の直後で改行するか）を保存する。
  旧データに改行フラグは無く、False として読み込む。
- 別PCへ渡す場合は、`data.json` 単体ではなくプロジェクトフォルダ全体を渡す。

この方式ではBase64化によるJSON容量の増加を避けられる。

## 操作

1. メニューの「画像」から「画像の登録・差し込み」を開く。
2. 「画像を登録」で元画像を選ぶ。
3. 指示文またはカギ文、挿入する文字位置、表示サイズを指定する。
   挿入位置は対象の文をクリックして指定することもできる。
4. 必要に応じて黒塗り方法と「画像の直後で改行する」を選び、
   「新しく差し込む」を押す。
   改行を有効にして挿入位置を 0 にすると、1行目に画像・2行目から
   文章のレイアウトになる。
   「挿入後のイメージ」欄で挿入後の見た目を確認できる。

登録後も、一覧から挿入位置・サイズ・黒塗り方法・改行を更新できる。
使われていない画像は「未使用画像を整理」でファイルごと削除できる。
別PCで画像が欠けた場合は「選択画像を再リンク」から置き換えられる。

## 黒塗り

- 黒塗りなし
- 透明部分以外を黒塗り
- 透明部分を含め全体を黒塗り

画像の黒塗りは「カギの黒塗りON/OFF」と連動する。OFFのときは元画像を表示する。
黒塗り用の描画画像は `picture/inline/.rendered/` に自動生成される。
