# CrossMaker 開発状況

更新日: 2026-08-01

この文書は、作業を中断しても同じ地点から再開できるように、実装済みの内容、検証状況、保留事項、次の推奨作業をまとめたものです。

## 現在の方針

- 実行ファイル版（デスクトップ版）とWeb版は別フォルダで管理する。
  - デスクトップ版: `app/`
  - Web版: `web/`
- 当面はデスクトップ版を優先する。
- デスクトップ版は PyQt6 に移行済み（2026-08-01）。実行環境は Python 3.11 + PyQt6。
  起動は `py -3.11 -m app`。
- 画像を使うプロジェクトは、JSONだけでなく `picture/` を含むプロジェクトフォルダ全体を受け渡す。
- プロジェクト形式はバージョン2。旧形式（バージョン0・1）も読み込める。

## デスクトップ版で実装済み

### 編集・出力

- マージン設定時に文字の黒塗り位置がずれる不具合を修正。
- 盤面とカギをまとめて消去する機能を追加。
- スクリーンショット取得時、一時的に約2倍で描画して高画質で保存する機能を追加。
- 文字の黒塗りをドラッグ操作で指定できるようにした。
  - 文字位置へのスナップ
  - 逆方向のドラッグ
  - 選択範囲のプレビュー

### 文中画像

- 指示文・タテのカギ・ヨコのカギの途中へ画像を挿入できる。
- 同じ画像を複数箇所で再利用できる。
- 挿入位置、表示サイズ、縦横比固定を配置ごとに設定できる。
- 画像の黒塗り方法を選べる。
  - 黒塗りなし
  - 透明部分を除いて黒塗り
  - 透明部分を含む画像全体を黒塗り
- 使われていない画像を確認して削除できる。
- 画像ファイルが見つからない場合、別ファイルへ差し替えられる。
- 画像本体は `picture/inline/` に保存し、JSONには相対パスと配置情報だけを保存する。

詳細は `docs/inline-images.md` を参照。

### 実画面確認からの改善（2026-08-01）

- 盤面列挙で結果が 0 件になる問題を修正。原因は「1 文字カギ禁止」の
  固定ルールで、クロスしない 1 文字マスを含む実際の盤面が除外されていた。
  - 「クロスしない 1 文字マスを許可」（既定オン）と
    「黒マスが点対称の盤面に限る」（既定オン）のチェックボックスを追加。
  - 点対称でない盤面も探索できる汎用探索を実装
    （上優先番号の前方一致による枝刈り付き）。
  - 実盤面（save/nasu の 6×6）のカギ番号から元の盤面が
    復元できることをテストで保証。
- 列挙結果のプレビューにカギ番号を表示。反映方式の切り替えに追随する。
- 画像差し込みの操作性を改善。
  - 対象の文に赤いキャレットで挿入位置を表示（クリックで指定も可能）。
  - 差し込み先プルダウンにカギ番号と本文冒頭を併記。
  - 黒塗り方法の既定を「透明部分以外を黒塗り」に変更。
  - 「挿入後のイメージ」欄を追加。実際の描画と同じ RichText 生成
    （`BlackOutText.render_rich_text`）で、挿入位置・サイズ・対象の
    変更に追随してプレビューする。差し込み済み項目の編集中は
    その項目を置き換えた状態を表示する。
  - 「画像の直後で改行する」オプションを追加（`line_break` フィールド、
    旧データは False として読み込む）。1行目に画像・2行目から文章の
    レイアウトができる。なおカギ本文の入力欄は1行入力のため、
    本文自体への改行入力は未対応。

### カギ番号と盤面列挙

- カギ番号の振り方を選択できる。
  - 上優先
  - 左優先
- 優先方法が不明な場合は、両方を探索して同じ盤面を重複表示しない。
- タテ・ヨコのカギ番号の組み合わせと矛盾しない盤面を列挙できる。
- 黒塗りで不明な番号も、成立する候補を探索する。
- 次の制約を適用する。
  - 正方形
  - 4x4から9x9
  - 1文字カギを禁止
  - 黒マス同士の上下左右の隣接を禁止
  - 白マスが一つにつながる
  - 黒マスが点対称
- 探索候補をプレビューし、現在の盤面へ反映できる。
- 探索の中断、進捗表示、結果件数の上限に対応。
- 盤面サイズとカギ数の偶奇から中央マスを確定するなど、枝刈りを実装。
- 対称性を利用して盤面の上半分だけを列挙するなど、探索量を削減。

詳細は `docs/board-enumerator.md` を参照。
