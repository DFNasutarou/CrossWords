# CrossMaker Web

CrossMakerのWeb版です。実行ファイル版とは分離して `web/` 内に実装しています。

## 現在の機能

- 既存の `data.json` の読み込み
- クロスワード盤面、指示文、タテ・ヨコのカギの表示
- JSONファイルの書き出し
- IndexedDBを使った端末内への自動保存
- 次回アクセス時の前回プロジェクト自動復元
- 複数プロジェクトの一覧・再読込・個別削除・全削除
- ブラウザの保存容量表示と永続保存の申請
- 4×4から9×9の既存プロジェクト形式に対応

ブラウザ内のデータは端末ローカルです。クラウドへの送信やアカウント登録は行いません。
